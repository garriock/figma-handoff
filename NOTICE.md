# Notice

This plugin's guidance was informed by the following published work. No text, stamps or schema files from these projects are included.

- [GitHub Annotation Toolkit](https://github.com/github/annotation-toolkit) (CC-BY 4.0), for accessibility annotation tiers and checkpoints.
- [Specs](https://github.com/DirectedEdges/specs) by Directed Edges (CC BY 4.0), for the idea of describing states as a default plus changes.
- Nathan Curtis's writing on component specifications.
- Figma's documentation on developer handoff, Dev Mode and the MCP server.
- W3C's WCAG 2.2 and ARIA Authoring Practices.

The plugin depends on Figma's MCP server and skills, which are Figma's own and are not included here.
